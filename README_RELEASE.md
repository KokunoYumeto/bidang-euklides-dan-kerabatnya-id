# Rilis lengkap Bahasa Indonesia

Repositori ini mempertahankan dua rilis yang sengaja dipisahkan berdasarkan
hak komponennya.

## Kursus utama

Tag: `2026.08.25-complete-course-a11y-ch20-portable`

Rilis CC BY-SA 4.0 ini memuat keseluruhan 20 bab buku sumber, pendamping
orisinal enam unit, seluruh solusi dan bahan penguasaan, HTML/EPUB lengkap,
empat pemeriksaan kumulatif, dua capstone, manifest, checksum, serta paket
sumber/backend yang dapat dilanjutkan. DOI:
<https://doi.org/10.5281/zenodo.22102628>.

Sumber resmi dipatok pada commit
`0b0858e1e985f4c8dadbb6075ae9e095cd4a8981`; saksi terbit adalah arXiv
`1302.1630v25`. Adaptasi ini independen dan tidak disahkan oleh penulis sumber.

## Buku kerja terpisah

Tag: `2026.08.29-unit001-022`

Rilis ini memuat *Buku Kerja Geometri Dua Dimensi* Unit 001–022. Narasinya
berlisensi CC BY-NC-SA 4.0 dan lapisan bangunnya GPL-2.0, sehingga tidak
digabung atau dilisensikan ulang sebagai bagian kursus utama. DOI:
<https://doi.org/10.5281/zenodo.22151703>.

Manifest dan berkas checksum pada masing-masing rilis adalah inventaris
normatif. Pembaca HTML lengkap tersedia melalui GitHub Pages pada
<https://kokunoyumeto.github.io/bidang-euklides-dan-kerabatnya-id/>.
